# Informe Final de Estadística Multidimensional - Wisconsin Breast Cancer Dataset

*English version below*

## Descripción del Proyecto
Este proyecto representa el trabajo final para la asignatura de Estadística Multidimensional. Consiste en un enfoque integrado en oncología computacional utilizando el conjunto de datos de cáncer de mama de Wisconsin (Diagnostic). El objetivo principal es evaluar, caracterizar y modelar la estructura multidimensional de las propiedades morfológicas y de textura de núcleos celulares obtenidos por FNAB (Biopsia por Aspiración con Aguja Fina) para discriminar de forma óptima masas benignas de malignas.

## Objetivos
1. **Reducción de Dimensionalidad**: Implementar un Análisis de Componentes Principales (PCA).
2. **Inferencia Multivariante**: Desarrollar un Análisis de Varianza Multivariante (MANOVA).
3. **Modelado de Constructos Ocultos**: Aplicar un Análisis Factorial Exploratorio (EFA).
4. **Evaluación Predictiva**: Diseñar y comparar un pipeline de clasificación supervisada (Regresión Logística, LDA, Árboles de Decisión y PCA + kNN).

## Conjunto de Datos
Se utiliza el **Breast Cancer Wisconsin (Diagnostic) Dataset** del repositorio de Machine Learning de la UCI. Contiene 569 observaciones y 32 variables asociadas a características morfológicas y de textura de células mamarias.

## Tecnologías Utilizadas
- R y RMarkdown
- Paquetes principales: `tidyverse`, `MASS`, `psych`, `caret`, entre otros.

# Multidimensional Statistics Final Report - Wisconsin Breast Cancer Dataset

## Project Description
This project is the final assignment for the Multidimensional Statistics course. It features an integrated computational oncology approach using the Wisconsin Breast Cancer (Diagnostic) dataset. The main goal is to evaluate, characterize, and model the multidimensional structure of morphological and texture properties of cell nuclei obtained by FNAB (Fine Needle Aspiration Biopsy) to optimally discriminate benign from malignant masses.

## Objectives
1. **Dimensionality Reduction**: Implement Principal Component Analysis (PCA).
2. **Multivariate Inference**: Develop a Multivariate Analysis of Variance (MANOVA).
3. **Modeling Hidden Constructs**: Apply Exploratory Factor Analysis (EFA).
4. **Predictive Evaluation**: Design and compare a supervised classification pipeline (Logistic Regression, LDA, Decision Trees, and PCA + kNN).

## Dataset
The project uses the **Breast Cancer Wisconsin (Diagnostic) Dataset** from the UCI Machine Learning Repository. It contains 569 observations and 32 variables associated with the morphological and textural characteristics of breast cells.

## Technologies Used
- R and RMarkdown
- Main packages: `tidyverse`, `MASS`, `psych`, `caret`, among others.
